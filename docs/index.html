Use your WHOOP strap without a subscription.

Edge pairs with your band over Bluetooth, decodes what it recorded, and computes your sleep, recovery, strain and other metrics on your phone. It needs no account or subscription, and no server receives your health data.

Get it on iOS TestFlight beta Get it on Android APK from Releases

Supports

  • WHOOP 4, WHOOP 5, MG : sleep, recovery, strain and the other metrics, all computed on-device. WHOOP 4 is the most tested model.
  • Any standard Bluetooth heart-rate strap : pairs for workout tracking. Edge stores and shows heart rate and beat timing. Full metrics are planned.
  • Oura Ring : the protocol code is in the repository, but the app cannot pair with it yet.

More devices are in development, with no release date. See the protocol repo for what's decoded so far.

It runs on your phone

The band sends bytes to the app. The app decodes them, computes every metric on the phone, and stores the results on the device. No server receives your health data.

GitHub Release builds send anonymous crash diagnostics by default. You can switch them off. Store builds send none. Neither build sends health data. Detail →

Published methods, cited

The metrics use Banister TRIMP (training load), Cole-Kripke (sleep scoring), Lomb-Scargle (heart-rate variability from uneven beat spacing) and van Hees (wrist-angle sleep detection). The analytics code cites the paper for each method.

Missing data shows as a dash

Every metric carries a confidence and a tier. When data is missing, the app shows a dash. SpO2 and skin temperature are relative-only, because the band does not report absolute values.

How it differs from WHOOP

OpenStrap applies published methods to the decoded band data. It does not use WHOOP's algorithms, so its numbers differ from WHOOP's.

Before you install

  • Quit the official WHOOP app before pairing. Bluetooth only lets one app own the band at a time.
  • Use one app per band. A firmware update from the official app could change the records OpenStrap reads, and OpenStrap cannot undo it.
  • Not medical-grade. These are approximations from published research, not validated against a lab. Nothing here is a diagnosis.
  • There are bugs. It’s a beta built by one person. Open an issue when something looks wrong. Reports are the most useful contribution.

How it’s put together

band → Bluetooth → protocol decoder → local storage → analytics → the UI

edge The app. Bluetooth, storage, the compute pipeline, every screen. protocol Decodes raw band bytes into named fields. Pure Dart with no dependencies. analytics Computes HRV, sleep staging, readiness and strain, with paper citations in the code. research Protocol documentation and a Python client.
