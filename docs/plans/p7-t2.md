# T2 learning design

TracksStore owns durable learning state and audit records. SQLite transactions serialize changes. Workers estimate effects from time-ordered nights. Missing data and failed guards abstain. Kinetics remain fixed through a global 28-day observation period and each field's minimum. Per-field periods are bounded, and tolerance/withdrawal wait for the greater of five half-lives and withdrawal duration. Steps change 1–3% of a field scale and respect locks.

The night adjustment is the existing max/min/OR ConfounderProfile monoid, extended with a set of user track identities and explanatory labels. Union preserves identity, associativity and commutativity. Preset behavior remains unchanged. Natural wake histories partition on the complete active identity set; independent user tracks cannot borrow warm-up nights.

Count, mean and M2 accumulators merge with the Welford formula. Effects are per selected system, shrink toward a preset prior or zero, and require matched clean comparisons, logging completeness, coverage, time ordering, identifiable co-exposures and permutation/negative-control checks with a family-wise threshold. Unsupported or inseparable effects stay absent. These are observational associations, not causal findings.

Slow-field fits use an explicit engineering model. Daily dose is normalized to the wearer's median logged daily amount. Tolerance approaches one on exposure days using the entered tolerance-days scale and decays on abstinent days using the entered withdrawal-days scale; each scale denotes 90% approach or loss. Effective residual and abstinence pressure receive independently fitted outcome coefficients. No population effect size is assumed. A complete history across ten entered scales, varied exposure runs or abstinence intervals, and at least 20% improvement on later held-out outcomes are required before a field can receive a proposal. The history window is bounded at 730 days; longer unidentified histories abstain.

Immediate residual/dose/timing/next-night terms retain a 48-hour window. Unknown-time events and setup history preserve unknown exposure. Sleep debt is computed by the existing analytics function from prior observed sleep durations and weekend durations, using the same convention as the cross-day pipeline. It is never substituted with zero. Matching and baselines use only information available before the outcome; negative controls precede the exposure window.

Registered workers receive immutable database snapshots. TracksStore compares definitions, medication metadata, events, history, explicit absences, learning state and day rows before atomically replacing state, a changed definition and its audit. A repeated or concurrent refresh cannot apply another step that local date. Cross-day orchestration refreshes learning after persisting nights; hub reads can also refresh it. User wake parameters partition on the complete active identity set and preset context. Their signed offsets combine by strongest magnitude per field, with positive winning ties and zero as identity, so overlapping identities cannot multiply a learned step.

Numerical policy choices, including 28 days globally, 12 matched pairs, 80% recording coverage, matching calipers, shrinkage weight eight and bounded permutation trials, are engineering gates. The estimator accepts a preset prior when one has been supplied in outcome units; without a validated numeric preset effect, production uses a zero-centered prior. Literature dose-specific findings are not converted into unsupported per-person effects.
