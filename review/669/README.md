# Pairing PR screenshots

Actual Flutter widget renders for OpenStrap/edge PRs 691 and 693–696. The device names and pairing results are fixtures; native BLE and AccessorySetupKit were not exercised. No physical iPhone test is claimed.

Each section was rendered from its corresponding split branch. See manifest.json for source commits. PNGs use a 412-logical-pixel width and 2x rendering; viewport height is 915 except the standalone reset-help component (1250). Bundled Manrope substitutes for unavailable SF Pro Text in the Linux widget-test renderer. Production fonts and UI code are unchanged.

The comparison section received test-only corrections after capture; its rendered UI is unchanged.
